# TravelGuide

A static multi-page travel discovery website built with HTML5, CSS3, Vanilla JavaScript and JSON content.

- `npm run build` emits static files into `dist/`.
- `npm run check` validates the homepage foundation and referenced WebP assets.
- Source lives in `src/`; generated output lives in `dist/`.
- No backend, database, authentication or SPA framework.

The homepage is the first page-family implementation. Destination, itinerary and article detail pages belong to later development tasks.

The current Pages hostname is a temporary preview canonical with `noindex, nofollow`. Confirm the canonical production hostname and Pages build settings before production deployment.
